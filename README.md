日本インフラクタル株式会社（Nihon Infractal Inc.）製 GPS NTPサーバ「LoModUs NTP」のサポート情報を公開しているリポジトリです。

設置担当者・保守担当者・システム管理者の方が、現場で必要な情報にすぐたどり着けることを目的としています。

---

## LoModUs NTP とは

GPS衛星からの時刻信号をもとに、マイクロ秒精度の時刻を配信する産業用 Stratum 1 NTPサーバです。インターネット接続を必要とせず、IP-VPN などの閉域ネットワーク上で時刻源として機能します。

大きくずれた既存システムの時刻を、ロギングデータの連続性を損なわずに毎日少しずつ修正する **キャッチアップ機能** を搭載しています。
