## 1. 目的

監視制御システム（SCADA）などで使われる閉域網のWindowsパソコンを、指定したNTPサーバに約17分（1024秒）ごとに同期させるためのツールです。

Windowsの時刻同期の設定は、画面・コマンド・レジストリに分散しており、手作業では設定漏れや入力ミスが起きやすくなっています。特に、閉域網では次のような状態に気づかないまま運用されていることがあります。

- Windows Timeサービスが停止している
- 参照先にインターネット上のサーバ（time.windows.com）が残っている
- 同期間隔が1週間（604800秒）などの長い値になっている

このツールは、これらの状態を確認し、必要な設定をまとめて行います。NTPサーバの種類は問いません。

## 2. 同梱ファイル

| ファイル名 | 役割 | 設定の変更 |
|---|---|---|
| `NI_TimeSync_Check.bat` | 時刻同期の状態を確認し、OK/NGを表示する | しない |
| `NI_TimeSync_Setup.bat` | 時刻同期の設定を標準の値に揃え、すぐに同期させる | する |
| `README_ja.md` | この説明書 | － |

どちらのツールも、**管理者として実行**する必要があります。

## 3. 対象と対象外

**対象**

- Windows 7 以降のパソコン、Windows Server 2008 R2 以降のサーバ
- ワークグループ構成（ドメインに参加していない）のパソコン

**対象外**

- **Windowsドメインに参加しているパソコン**。ドメインのパソコンは、ドメインコントローラーから時刻を取る別の仕組みで動いています。このツールで設定を変えると、その仕組みを壊すおそれがあります。

## 4. 標準の設定値

確認用ツールは、次の値をOKと判定します。設定用ツールは、この値に設定します。

| 項目 | 標準の値 | 意味 |
|---|---|---|
| Windows Timeサービス | 実行中・自動起動 | 時刻同期を行うサービスが常に動いている |
| Sync type（Type） | `NTP` | 指定したNTPサーバから時刻を取る |
| NTP server（NtpServer） | `IPアドレス,0x9` | 参照先のNTPサーバ。`0x9` は下の同期間隔を使う指定 |
| Sync interval（SpecialPollInterval） | `1024`（秒） | 約17分ごとに同期する |
| Time source | NTP serverと同じ値 | 実際にそのサーバから時刻を取れている |

## 5. 使い方

### 5.1 準備

1. 2つのバッチファイルを、NASなどを使って対象のパソコンに持ち込みます。
2. **2つとも、対象のパソコンのデスクトップにコピーします。**
   NAS上のファイルを直接「管理者として実行」すると、Windowsの仕様でファイルが見つからず失敗することがあります。

### 5.2 状態を確認する

1. `NI_TimeSync_Check.bat` を右クリックし、「管理者として実行」を選びます。
2. 結果の6項目がすべて `[OK]` なら、設定は不要です。
3. `[NG]` がある場合は、次の手順で設定します。

### 5.3 設定する

1. 必要に応じて、`NI_TimeSync_Setup.bat` をメモ帳で開き、先頭の `DEFAULT_NTP` にNTPサーバのIPアドレスを書きます（下記「5.4」参照）。
2. `NI_TimeSync_Setup.bat` を右クリックし、「管理者として実行」を選びます。
3. NTPサーバのIPアドレスを確認します。`[ ]` 内の値でよければEnter、違う場合は正しい値を入力してEnterを押します。
4. 接続テストの結果を確認します。
   - 時刻の差（例：`-00.0031764s`）が表示された場合：接続できています。
   - エラー（例：`エラー: 0x800705B4`）が表示された場合：接続できていません。原則として `N` を選んで中止し、IPアドレスとネットワークを確認します。
5. **時刻が飛ぶことについての警告を読み**、実施してよければ `Y` を押します（下記「6. 注意事項」参照）。
6. 設定後、確認用ツールが自動で実行され、結果が表示されます。すべて `[OK]` なら完了です。

### 5.4 IPアドレスの初期値の決まり方

設定用ツールが表示する初期値は、次の順で決まります。

| 優先順位 | 初期値 | 使う場面 |
|---|---|---|
| 1 | ファイル先頭の `DEFAULT_NTP` に書いた値 | NTPサーバの新設・入れ替え時。ファイルを1回書き換えれば、全台でEnterを押すだけで済む |
| 2 | そのパソコンに今設定されているNTPサーバ | 既存の設定の修復時。ファイルの書き換えは不要 |
| 3 | なし（入力を求める） | 1も2もない場合、または今の設定が time.windows.com の場合 |

`DEFAULT_NTP` の書き方の例：

```
set DEFAULT_NTP=192.168.1.1
```

## 6. 注意事項

- 設定の直後の同期によって、パソコンの時刻はNTPサーバの時刻に一気に修正されます。対象のシステムが時刻の変動を許容できるか確認し、必要に応じて、段階的にシステムの時刻修正が可能な、LoModUs NTP（日本インフラクタル株式会社製）のキャッチアップ機能の使用を検討してください。
- サービスの起動直後は、Time sourceが一時的にNGになることがあります。数分待ってから、確認用ツールで再確認してください。
- Windowsの「インターネット時刻」タブの表示は正確ではない場合があります。コントロールパネルの「日付と時刻」→「インターネット時刻」タブは、設定中のサーバ名と最後に同期した日時を並べて表示しますが、実際にどのサーバと同期したかは示しません。判定は確認用ツールの Time source で行ってください。
- 本バッチファイルを編集する場合は、半角英数字だけを使うことを推奨します。日本語を使う場合は、必ずShift-JISで保存してください。

## 7. よくある表示とエラー

| 表示 | 意味 | 対処 |
|---|---|---|
| `ERROR: This tool needs administrator rights.` | 管理者として実行されていない | 右クリック→「管理者として実行」 |
| `エラー: 0x800705B4` | NTPサーバから応答がない（タイムアウト） | IPアドレス、ネットワーク、NTPサーバの稼働状態を確認 |
| `アクセスが拒否されました。(0x80070005)` | 管理者権限がない | 右クリック→「管理者として実行」 |
| Time source が `Local CMOS Clock` | NTPサーバと同期できておらず、パソコン内部の時計で動いている | 設定用ツールを実行する。改善しない場合は接続を確認 |
| Time source が `Free-running System Clock` | 同上 | 同上 |
| NTP serverに `/syncfromflags:manual /update` などの文字列が含まれている | 過去の手入力で、コマンドの一部がサーバ名として登録されている | 設定用ツールを実行すると正しい値に上書きされる |
| Sync interval が `604800` | 同期が1週間に1回しか行われない（Windowsの古い既定値） | 設定用ツールを実行する |

## 8. 参考：手作業で設定する場合

ツールを使えない場合は、**管理者権限のコマンドプロンプト**で次を1行ずつ実行します。`192.168.1.1` は実際のNTPサーバのIPアドレスに置き換えてください。

```
sc config w32time start= auto
reg add HKLM\SYSTEM\CurrentControlSet\Services\W32Time\Parameters /v Type /t REG_SZ /d NTP /f
reg add HKLM\SYSTEM\CurrentControlSet\Services\W32Time\Parameters /v NtpServer /t REG_SZ /d 192.168.1.1,0x9 /f
reg add HKLM\SYSTEM\CurrentControlSet\Services\W32Time\TimeProviders\NtpClient /v SpecialPollInterval /t REG_DWORD /d 1024 /f
net stop w32time
net start w32time
w32tm /resync
```

手作業での注意点：

- **PowerShellではなく、コマンドプロンプトを使ってください。** PowerShellでは `sc` が別のコマンドになり、カンマも別の意味に解釈されます。管理者権限のPowerShellしか開けない場合は、その中で `cmd` と入力すると、管理者権限のままコマンドプロンプトに切り替わります。
- **日本語入力（IME）をオフにしてください。** 全角の「/」やスペースが混ざると、「次の引数は予期されていません」というエラーになります。
- **`sc config` の `start=` の後には、半角スペースが必要です。**

## 9. 動作確認の状況（v1.1）

Windows 11 で次の動作を確認しています。

- 通常の実行（ダブルクリック）で、管理者権限のエラーを表示して終了すること
- 確認用ツールが、同期できている状態・同期できていない状態を正しく判定すること
- 設定用ツールが、現在の設定値を初期値として表示すること
- 設定用ツールが、NTPサーバに接続できない場合にエラーを表示し、`N` で何も変更せずに終了すること

NTPサーバに接続できる状態で `Y` を選んだ場合の一連の動作（設定・サービス再起動・同期・確認）は、今後の現場で確認予定です。
